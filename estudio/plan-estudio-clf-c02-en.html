Week-by-week plan
Week 1 — Domain 1: Cloud Concepts (24%)
1.1
What cloud computing is and its benefits
Trade capital for variable expense, economies of scale, stop guessing capacity, speed and agility, stop investing in your own infrastructure, go global in minutes.
1.2
AWS Cloud Adoption Framework (CAF)
Six perspectives: business, people, governance, platform, security, and operations. Not sequential steps.
1.3
Well-Architected Framework
Six pillars: operational excellence, security, reliability, performance efficiency, cost optimization, and sustainability.
1.4
Migration strategies (the 7 R's)
Rehost, replatform, repurchase, refactor, retire, retain, and relocate.

Week 2 — Domain 2: Security and Compliance (30%)
2.1
Shared responsibility model
AWS secures the cloud (physical infrastructure, virtualization). The customer secures what they put in the cloud (data, access, configuration), in different proportions depending on the service.
2.2
AWS IAM
Root user, users, groups, roles, policies, MFA, principle of least privilege, IAM Identity Center.
2.3
Compliance, audit, and governance
AWS Artifact, Audit Manager, Config, CloudTrail, Organizations, Control Tower.
2.4

Service catalog by domain · quick reference

Filter by domain to review only the services you need for each week. This exam only requires recognizing each service's "job title."

AWS CAF
Six perspectives for organizing the transformation toward the cloud: business, people, governance, platform, security, operations.
AWS Well-Architected Tool
Evaluates workloads against the framework's six pillars and suggests improvements.
AWS Snow Family
Physical devices for migrating large volumes of data to AWS when the network isn't enough.
AWS Application Discovery Service
Discovers and collects information from on-premises servers to plan a migration.
AWS Migration Hub
Central dashboard for tracking migration progress across different AWS tools.
AWS IAM
Users, groups, roles, and policies for controlling who can do what to which resource.
AWS Organizations
Centralized management of multiple accounts, with service control policies and consolidated billing.
Amazon GuardDuty
Intelligent threat detection that analyzes account logs for malicious activity.
Amazon Macie
Discovers and classifies sensitive data stored in Amazon S3 buckets.
AWS KMS
Creates and manages the keys used to encrypt data at rest.
AWS Artifact
Self-service portal for downloading AWS compliance reports (SOC, ISO).
AWS CloudTrail
Records every API call made in the account: who did what, when, and from where.
AWS Shield / WAF
Shield protects against DDoS attacks. WAF filters malicious traffic to a web application.
Amazon EC2
Resizable virtual servers with full control over the operating system.
AWS Lambda
Runs code without provisioning servers, billing only for execution time.
Amazon ECS / EKS
Container orchestration: ECS is AWS's own option, EKS is managed Kubernetes.
Amazon S3
Object storage with high durability, for any type and volume of file.
Amazon EBS / EFS
EBS is a disk for a single EC2 instance. EFS is a file system shared across multiple instances.
Amazon RDS / Aurora
Managed relational databases. Aurora is AWS's higher-performance version.
Amazon DynamoDB
Fully managed NoSQL key-value database, with millisecond latency at any scale.
Amazon VPC
An isolated, private virtual network within AWS, where resources are deployed.
Amazon CloudFront
Content delivery network that distributes content from edge locations close to the user.
Amazon Route 53
Managed DNS service, also used for traffic routing and health checks.
AWS Direct Connect
Dedicated, private network connection between an on-premises data center and AWS.
Amazon CloudWatch
Monitors metrics, logs, and alarms across AWS resources and applications.
AWS CloudFormation
Provisions infrastructure as code through repeatable templates.
AWS Trusted Advisor
Automated recommendations on cost, security, performance, and resilience best practices.
Amazon SageMaker AI
Platform for building, training, and deploying your own machine learning models.
Amazon Q
AWS's generative assistant: Q Developer for code, Q Business for company data.
AWS Pricing Calculator
Estimates the cost of an architecture before deploying it.
AWS Cost Explorer
Visualizes and analyzes spend and usage patterns over time.
AWS Budgets
Sets budgets and alerts when spend approaches or exceeds a defined limit.
AWS Marketplace
Catalog of third-party software ready to run on AWS.
Business Support+ / Enterprise Support
Paid support plans with different response times and levels of technical guidance.
