Week 1 — Foundation Models + Amazon Bedrock core
D1 · 31%
Foundation Models: key concepts
FM types (LLM, multimodal, embedding). Context window, tokenization, temperature, top-p, top-k. Capabilities vs limitations. When to use FM vs classic ML.
D1 · 31%
Amazon Bedrock core
Model catalog (Claude, Titan, Llama, Mistral). InvokeModel API. On-demand vs Provisioned Throughput vs Batch Inference. Bedrock Prompt Management.
D1 · 31%
FM selection and configuration
Choosing a model based on benchmarks, capabilities, and cost. Dynamic model selection with Lambda + AppConfig. Cross-Region Inference for availability. Graceful degradation strategies.
D1 · 31%
Basic and advanced prompt engineering
Zero-shot, few-shot, chain-of-thought. System prompts, role definitions. Bedrock Prompt Flows for chaining. Structured outputs with JSON Schema. Feedback loops for iterative improvement.
D1 · 31%
Data pipelines for FMs
Validation: AWS Glue Data Quality, SageMaker Data Wrangler. Multimodal processing: Transcribe (audio), Bedrock multimodal. JSON formatting for the Bedrock API. Amazon Comprehend for entity extraction.

Week 2 — RAG + Vector Stores + Embeddings + Knowledge Bases
D1 · 31%
Complete RAG architecture
Flow: ingestion → chunking → embedding → vector store → retrieval → augmentation → generation. RAG vs fine-tuning vs prompt-only. Amazon Bedrock Knowledge Bases as managed RAG.
D1 · 31%
Embeddings and vector stores
Amazon Titan Embeddings (dimensionality, use cases). Vector databases: OpenSearch Service (Neural plugin), Aurora pgvector, DynamoDB + vector. Similarity: cosine, dot product, euclidean.
D1 · 31%
Chunking strategies
Fixed-size, hierarchical, semantic chunking. Overlap between chunks. How chunk size affects retrieval quality. Bedrock's native chunking capabilities.
D1 · 31%
Advanced search and reranking
Hybrid search (keywords + vectors) beats vector-only. Amazon Bedrock reranker models. Query expansion and decomposition with Lambda. Metadata filtering to sharpen results.
D2 · 26%
Vector store maintenance
Incremental updates, real-time change detection, refresh pipelines. Monitoring with CloudWatch. Index optimization in OpenSearch. Sharding strategies for scale.

Critical difference, RAG vs fine-tuning: RAG = data that changes frequently or access to external sources (knowledge base, documents). Fine-tuning = changing the model's behavior/style, not its knowledge. The exam asks this directly.
Week 3 — Agentic AI + Implementation + Integration
D2 · 26%
Bedrock Agents
Action groups, knowledge bases, Lambda tools. ReAct pattern (Reasoning + Acting). Strands Agents and AWS Agent Squad for multi-agent setups. Stopping conditions, timeout mechanisms. Human-in-the-loop with approval workflows.
D2 · 26%
MCP (Model Context Protocol)
Stateless MCP servers on Lambda, more complex ones on ECS. MCP client libraries for standardized access. Purpose: give FMs standardized access to external tools.
D2 · 26%
Step Functions + Lambda for GenAI
Circuit breaker patterns. Prompt chaining. ReAct implementation. Error handling and retries.
D2 · 26%
FM API integrations: streaming
Bedrock Streaming APIs for real-time responses. WebSockets vs Server-Sent Events (SSE). API Gateway for chunked transfer encoding. Exponential backoff with the AWS SDK. X-Ray for tracing.
D2 · 26%
Model deployment and fine-tuning
On-demand vs Provisioned Throughput vs SageMaker. Fine-tuning in Bedrock: when to use it. LoRA/adapters (parameter-efficient). SageMaker Model Registry. CI/CD for models with CodePipeline.
D2 · 26%
Amazon Q Developer + Q Business
Q Developer: code assistant, generation, refactoring. Q Business: enterprise chatbot with internal sources. Bedrock Data Automation for workflows. Enterprise integration with EventBridge.

Week 4 — AI Safety + Security + Governance + Optimization
D3 · 20%
Amazon Bedrock Guardrails
Content filters (violence, hate, sexual). Topic denial policies. PII detection and redaction. Grounding checks to reduce hallucinations. Layered input AND output guardrails. Defense-in-depth.
D3 · 20%
Prompt injection and adversarial inputs
What prompt injection is in FMs. Detection with Comprehend + Lambda validators. Jailbreak detection. Input sanitization. Automated adversarial testing workflows.
D3 · 20%
PII and data privacy
Amazon Comprehend for real-time PII in text. Amazon Macie for PII in S3. Data masking and anonymization. VPC endpoints for Bedrock. Lake Formation for granular access.
D3 · 20%
Responsible AI: fairness, transparency, bias
Model cards with SageMaker AI. Fairness metrics in CloudWatch. Bedrock agent tracing for explainable reasoning. LLM-as-a-judge. A/B testing for bias. Auditing with CloudTrail.
D4 · 12%
Cost and token optimization
Token efficiency: context pruning, prompt compression, response limiting. Semantic caching to avoid repeated invocations. Model tiering by complexity. Batch inference. Provisioned Throughput for predictable workloads.
D4 · 12%
Monitoring GenAI with CloudWatch
Bedrock Model Invocation Logs for detailed analysis. CloudWatch: token usage, hallucination rates, latency. X-Ray for FM tracing. Anomaly detection for drift. Custom dashboards.
