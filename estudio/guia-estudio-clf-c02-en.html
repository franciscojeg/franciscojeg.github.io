What CLF-C02 tests

This exam doesn't ask you to configure anything. It asks you to recognize what each category of AWS services does, how the shared responsibility model works, how the cloud gets billed, and where to find help.

  1. Read the scenario for the category: is it compute, storage, database, networking, or security?
  2. Identify the deciding factor: cost, availability, latency, compliance, or ease of management.
  3. Eliminate by process of elimination: there are almost always two clearly wrong options and two similar ones; the trap is in those two.
  4. When in doubt, pick the managed service over the one requiring more manual administration, unless the scenario asks for full control.
Guiding question: "which service solves this need with the least operational effort?" In a foundational exam, the managed option almost always wins over the one that demands more manual setup.

Domain 1 · Cloud Concepts 24%

Benefits of the cloud
BenefitKey idea
Variable expenseYou pay for what you use, not upfront (CapEx → OpEx).
Economies of scaleLower prices from aggregating usage across thousands of customers.
Stop guessing capacityYou scale to actual demand.
Speed and agilityResources available in minutes.
Stop investing in infrastructureFocus on what differentiates the business.
Go global in minutesMulti-region deployment in a few clicks.
Hint: "no upfront investment" or "pay only for what you use" almost always points to variable expense.
AWS CAF: six perspectives

Business, People, Governance, Platform, Security, and Operations. Not sequential: they advance together during the transformation toward the cloud.

Well-Architected: six pillars
PillarQuestion
Operational ExcellenceCan I run and continuously improve?
SecurityAm I protected from unauthorized access?
ReliabilityDoes it recover quickly from failures?
Performance EfficiencyAm I using resources efficiently?
Cost OptimizationAm I delivering value at the lowest price?
SustainabilityAm I minimizing environmental impact?
Trap: sustainability is the newest pillar and the easiest to confuse with cost optimization. If the scenario mentions carbon or energy, it's sustainability.
The 7 R's of migration

Rehost (move as-is), Replatform (move with targeted improvements), Repurchase (switch to SaaS), Refactor (redesign), Retire (decommission), Retain (keep as-is) and Relocate (move without changes to another cloud platform, VPC, or account).

Hint: for large migrations, AWS recommends prioritizing rehost, replatform, relocate, and retire, leaving refactor for later.

Domain 2 · Security and Compliance 30% · second heaviest

Shared responsibility

AWS: security "of" the cloud (hardware, facilities, networking, virtualization). Customer: security "in" the cloud (data, access, configuration), in a proportion that varies by service.

Quick rule: the more abstracted the service (EC2 → S3 → DynamoDB), the more responsibility AWS takes on.
IAM at a glance
ElementWhat it is
Root userFull access, protect it with MFA, don't use it daily.
User / groupIndividual identity or a set sharing permissions.
RoleTemporary identity, no long-term credentials.
PolicyJSON document that allows or denies actions.
Trap: "least privilege" means granting only the access strictly needed, never broad access for convenience.
Compliance, audit, and specialized security
  • AWS Artifact: download compliance reports (SOC, ISO).
  • AWS CloudTrail: who did what and when (API auditing).
  • AWS Config: how a resource's configuration changed over time.
  • Amazon GuardDuty: threat detection.
  • Amazon Macie: discovers sensitive data in S3.
  • AWS KMS / Secrets Manager: encryption keys and credentials.
  • AWS Shield / WAF: DDoS protection and web application firewall.

Domain 3 · Cloud Technology and Services 34% · the heaviest

Global infrastructure
ConceptWhat it is
RegionA geographic location with several data centers.
Availability Zone (AZ)An independent data center within a region.
Edge locationA point of presence for CloudFront and Route 53.
Hint: high availability within one region → multiple AZs. Proximity to global users → multiple regions or CloudFront.
Compute, containers, and storage
ServiceWhat it's for
Amazon EC2Virtual servers with full control over the OS.
AWS LambdaServerless code, billed only for execution.
ECS / EKS / FargateContainer orchestration, with or without managing instances.
Amazon S3Object storage, with classes from Standard to Glacier Deep Archive.
Amazon EBSA disk for a single EC2 instance.
Amazon EFSA file system shared across multiple instances.
Trap: S3 is not a disk (that's EBS) or a shared file system (that's EFS). S3 is object storage accessible via API or HTTP.
Databases and networking
ServiceWhat it's for
Amazon RDS / AuroraManaged relational databases; Aurora is the higher-performance one.
Amazon DynamoDBNoSQL key-value, milliseconds at any scale.
Amazon VPCAn isolated private network within AWS.
Amazon Route 53Managed DNS.
Amazon CloudFrontCDN from edge locations.
AWS Direct ConnectDedicated, private connection, bypassing the internet.
Monitoring, governance, and AI/ML
  • Amazon CloudWatch: metrics, logs, and alarms (performance and health).
  • AWS CloudFormation: infrastructure as code.
  • AWS Trusted Advisor: automated best-practice recommendations.
  • Amazon SageMaker AI, Rekognition, Textract, Comprehend, Amazon Q: AI/ML services, only at the level of recognizing what each does.
Hint: CloudTrail (who did what) vs. Config (how configuration changed) vs. CloudWatch (performance and health): the three most common mix-ups in the exam.

Domain 4 · Billing, Pricing, and Support 12%

Pricing models
ModelWhen it fits
On-DemandNo commitment, most expensive per hour.
Reserved InstancesUp to 72% off with a 1 to 3 year commitment.
Savings PlansA similar discount, committing to spend instead of instance type.
SpotUp to 90% off, but interruptible.
Trap: Spot is the cheapest but least reliable. On-Demand requires no commitment but is the most expensive per hour.
Support plans
PlanWho it's for
BasicAlways included, at no extra cost.
Business Support+24/7, <30 min response on critical cases, production workloads.
Enterprise SupportEverything above plus a dedicated TAM, <15 min response.
Note: the official guide still names Developer, Business, and Enterprise On-Ramp Support. AWS is retiring them in favor of Business Support+ and Enterprise Support on January 1, 2027; the logic of "who needs which plan" doesn't change.
Cost tools
  • Pricing Calculator: estimate before deploying.
  • Cost Explorer: analyzes historical spend and forecasts.
  • AWS Budgets: alerts when approaching a limit.
  • AWS Organizations: consolidated billing across accounts.
