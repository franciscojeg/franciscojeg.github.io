Semana 1 — Dominio 1: Conceptos de la nube (24%)
1.1
Qué es cloud computing y sus beneficios
Gasto variable en vez de capital, economías de escala, dejar de adivinar capacidad, velocidad y agilidad, dejar de invertir en infraestructura propia, ir global en minutos.
1.2
AWS Cloud Adoption Framework (CAF)
Seis perspectivas: negocio, personas, gobernanza, plataforma, seguridad y operaciones. No son pasos secuenciales.
1.3
Well-Architected Framework
Seis pilares: excelencia operacional, seguridad, fiabilidad, eficiencia de rendimiento, optimización de costos y sostenibilidad.
1.4
Estrategias de migración (las 7 R)
Rehost, replatform, repurchase, refactor, retire, retain y relocate.

Semana 2 — Dominio 2: Seguridad y cumplimiento (30%)
2.1
Modelo de responsabilidad compartida
AWS asegura la nube (infraestructura física, virtualización). El cliente asegura lo que pone en la nube (datos, accesos, configuración), en distinta proporción según el servicio.
2.2
AWS IAM
Usuario raíz, usuarios, grupos, roles, políticas, MFA, principio de privilegio mínimo, IAM Identity Center.
2.3
Cumplimiento, auditoría y gobernanza
AWS Artifact, Audit Manager, Config, CloudTrail, Organizations, Control Tower.
2.4
Servicios de seguridad especializados
GuardDuty, Inspector, Macie, KMS, Secrets Manager, Shield, WAF, Security Hub.

Catálogo de servicios por dominio · referencia rápida

Filtra por dominio para repasar solo los servicios que necesitas en cada semana. En este examen basta con reconocer el "título de trabajo" de cada servicio.

AWS CAF
Seis perspectivas para organizar la transformación hacia la nube: negocio, personas, gobernanza, plataforma, seguridad, operaciones.
AWS Well-Architected Tool
Evalúa cargas de trabajo contra los seis pilares del framework y sugiere mejoras.
AWS Snow Family
Dispositivos físicos para migrar grandes volúmenes de datos hacia AWS cuando la red no alcanza.
AWS Application Discovery Service
Descubre y recolecta información de servidores on-premises para planificar una migración.
AWS Migration Hub
Panel central para rastrear el progreso de migraciones a través de distintas herramientas de AWS.
AWS IAM
Usuarios, grupos, roles y políticas para controlar quién puede hacer qué sobre qué recurso.
AWS Organizations
Administración centralizada de múltiples cuentas, con políticas de control de servicios y facturación consolidada.
Amazon GuardDuty
Detección inteligente de amenazas analizando logs de la cuenta en busca de actividad maliciosa.
Amazon Macie
Descubre y clasifica información sensible almacenada en buckets de Amazon S3.
AWS KMS
Crea y administra las llaves usadas para cifrar datos en reposo.
AWS Artifact
Portal de autoservicio para descargar reportes de cumplimiento de AWS (SOC, ISO).
AWS CloudTrail
Registra cada llamada a la API de la cuenta: quién hizo qué, cuándo y desde dónde.
AWS Shield / WAF
Shield protege contra ataques DDoS. WAF filtra tráfico malicioso hacia una aplicación web.
Amazon EC2
Servidores virtuales redimensionables con control total del sistema operativo.
AWS Lambda
Ejecuta código sin aprovisionar servidores, cobrando solo por tiempo de ejecución.
Amazon ECS / EKS
Orquestación de contenedores: ECS es la opción propia de AWS, EKS es Kubernetes administrado.
Amazon S3
Almacenamiento de objetos con alta durabilidad, para cualquier tipo y volumen de archivo.
Amazon EBS / EFS
EBS es un disco para una sola instancia EC2. EFS es un sistema de archivos compartido entre varias instancias.
Amazon RDS / Aurora
Bases de datos relacionales administradas. Aurora es la versión de mayor rendimiento diseñada por AWS.
Amazon DynamoDB
Base de datos NoSQL de clave-valor totalmente administrada, con latencia de milisegundos a cualquier escala.
Amazon VPC
Red virtual privada y aislada dentro de AWS, donde se despliegan los recursos.
Amazon CloudFront
Red de entrega de contenido que distribuye contenido desde ubicaciones de borde cercanas al usuario.
Amazon Route 53
Servicio de DNS administrado, también usado para enrutamiento de tráfico y verificación de salud.
AWS Direct Connect
Conexión de red dedicada y privada entre un centro de datos propio y AWS.
Amazon CloudWatch
Monitoreo de métricas, logs y alarmas sobre los recursos y aplicaciones de AWS.
AWS CloudFormation
Aprovisiona infraestructura como código mediante plantillas repetibles.
AWS Trusted Advisor
Recomendaciones automáticas de mejores prácticas en costo, seguridad, rendimiento y resiliencia.
Amazon SageMaker AI
Plataforma para construir, entrenar y desplegar modelos de machine learning propios.
Amazon Q
Asistente generativo de AWS: Q Developer para código, Q Business para datos de la empresa.
AWS Pricing Calculator
Estima el costo de una arquitectura antes de desplegarla.
AWS Cost Explorer
Visualiza y analiza patrones de gasto y uso a lo largo del tiempo.
AWS Budgets
Define presupuestos y alertas cuando el gasto se acerca o supera el límite definido.
AWS Marketplace
Catálogo de software de terceros listo para ejecutarse en AWS.
Business Support+ / Enterprise Support
Planes de soporte pagos con distintos tiempos de respuesta y niveles de acompañamiento técnico.
