Critical trap (very frequent): VPC Endpoint Gateway (S3 and DynamoDB) is FREE and doesn't require NAT. VPC Endpoint Interface (other services) uses PrivateLink and has a cost. "Access S3 from private subnet cost-effectively" → always Gateway Endpoint.

Critical decision pairs - quick reference
ALB vs NLB vs Gateway Load Balancer
ALBLayer 7 (HTTP/HTTPS), path- or host-based routing, ideal for microservices and containers
VS
NLBLayer 4 (TCP/UDP), ultra-low latency, static IP, millions of requests per second
VS
Gateway Load BalancerLayer 3, for transparently inserting third-party appliances (firewalls, IDS/IPS)
RDS vs Aurora vs DynamoDB
RDSManaged relational (MySQL, PostgreSQL, etc.), control close to the original engine
VS
AuroraAWS-native relational, higher performance and faster replicas, Global Database
VS
DynamoDBNoSQL key-value, massive scale, single-digit millisecond latency
Reserved vs Savings Plans vs Spot
Reserved Instances1-3 year commitment tied to a specific EC2 instance family/size
VS
Savings PlansSpend commitment in USD/hour, flexible across EC2, Fargate, and Lambda
VS
Spot InstancesUp to 90% discount, can be interrupted, ideal for fault-tolerant batch jobs
S3 Storage Classes by access pattern
Standard / Intelligent-TieringFrequent or unpredictable access, no retrieval penalty
VS
Standard-IA / One Zone-IAInfrequent access but fast when needed
VS
Glacier (Instant / Flexible / Deep Archive)Archive, minutes to hours to retrieve, the cheapest for long-term retention
Route 53: routing policies
Latency-basedRoutes to the region with the lowest network latency for the user
VS
GeolocationRoutes based on the user's actual geographic location, not latency
VS
Weighted / FailoverDistributes traffic by a fixed percentage, or switches to a backup site if the primary fails its health check
KMS vs Secrets Manager vs Parameter Store
KMSManages the encryption keys themselves (CMK), the foundation of encryption in AWS
VS
Secrets ManagerStores secrets (passwords, API keys) with built-in automatic rotation
VS
SSM Parameter StoreConfiguration and parameters, can store SecureString, no native rotation
CloudTrail vs Config vs CloudWatch
CloudTrailWho made which API call and when, action auditing
VS
AWS ConfigWhat configuration a resource has now and how it changed over time, compliance
VS
CloudWatchPerformance metrics, application logs, and operational alarms
IAM User vs IAM Role vs Resource Policy
IAM UserLong-term identity with its own credentials, for people or fixed apps
VS
IAM RoleTemporary identity that gets assumed, ideal for AWS services or cross-account access
VS
Resource PolicyAttached to the resource (e.g. an S3 bucket), not the user, defines who can access it from outside
